## 확인했지만 문제 아님
- FSM 인터락·피드백 순서: BLOCK 진입은 on_interlock(True)→on_feedback(BLOCK)(중복 제거로 1회 송신), 해제는 feedback NONE→RUN, reset() 은 BLOCK/WARNING 에서도 RUN 을 보낸다.
- EMO: 해제·초기화는 레벨(`emo_active`)로 막는다. 바운스로 EMO 가 여러 번 들어와도 결과가 같다(멱등). 부팅 때 EMO 가 HIGH 이면 곧바로 보내는 경로는 `_init_ui` 뒤에 있어 위젯이 준비된 상태다.
- GPIO·카메라·인터락 콜백: 모두 시그널로 GUI 스레드에 넘기고, FSM 은 GUI 스레드에서만 다룬다.
- 좌표계: 검출 박스·손끝·링이 모두 「반전→왜곡보정→회전」 뒤 프레임 기준이고, 링 배율은 긴 변 기준이라 회전해도 같다.
