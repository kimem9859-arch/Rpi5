# raw 프레임 보관 (console_v2 시험대)

`bench_detector.py --save-raw`가 저장한 **무손실 PNG**. 각 이미지는 `detector.detect()`에
실제로 건네진 배열 그대로다(플립 적용 후). 손실 압축이 없으므로 재추론하면 **라이브 측정과
검출이 그대로 재현**된다 — 실제로 4세션 × 5클래스 = 20항목 전부 라이브 CSV와 일치 확인.

> ⚠️ `Demo/test/videos/*.mp4`는 **검출 오버레이가 그려진** 화면이고 mp4v 손실압축이라
> **재분석에 쓸 수 없다**. 반드시 이 raw를 쓸 것. (§10.9 요인분리를 mp4로 시도했다가
> 원본 조건에서도 B4가 0/20으로 나와 무효였던 전례가 있다.)

## 용도 — console_v2 평가

console_v1은 이 ESP32 프레임에서 **B4를 400장 중 0장** 검출했다(다른 4클래스는 정상).
원인은 입력의 고주파 손실 + 모델의 B4 표현이 경계에만 의존하는 취약성(§10.9·§10.10).

console_v2 학습 후, **하드웨어·조명·삼각대를 다시 세팅하지 않고** 같은 입력에 평가한다:

```bash
cd ~/sop-project/Rpi5/Demo
python3 test/replay_raw.py test/raw/20260710_173555_esp32 --hef models/console_v2.hef
```

**합격 기준**: 이 ESP32 raw에서 B4 검출률·신뢰도가 임계값(`YOLO_CONF_HIGH` 0.65) 위로 올라올 것.

기타:
```bash
python3 test/replay_raw.py <세션> --ablation          # 열화 요인 분리 재현
python3 test/replay_raw.py <세션> --conf-high 0.55    # 임계값 튜닝(재촬영 불필요)
```
