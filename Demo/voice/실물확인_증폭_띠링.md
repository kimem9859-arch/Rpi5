# 실물 확인 — 마이크 증폭 · 띠링 · 닫힘음

> 다음 실물 세션에서 **이 순서 그대로** 한다. 만든 날 2026-10-09 · 진행 상황 = `../../../docs/작업로그.md` ⏸/▶
> 코드 = Rpi5 `1aced76`(증폭 ×4 · 띠링 메아리 버림) · `f258561`(띠링 높이 · 닫힘음 C · 파이 쪽) · 도구 = `voice/glass_sound_check.py` · 굽기 = `arduino/flash_esp32.sh`
> 🔴 **관문은 재기 전에 고정했다 — 결과를 보고 바꾸지 않는다.** 미달이면 멈추고 보고한다.
> 걸리는 시간 ≈ 25분(굽기 백업이 가장 길다).

## 왜 하나 (한 줄씩)

- **증폭** — 안경 프레임 안(관자놀이) 착용이면 말소리가 작아 호출이 0/10 이었다 → ×4. 10/8 녹음을 다시 돌린 값은 호출 10/12(실물 아님).
- **띠링 메아리** — 프레임 안에서 스피커가 마이크 바로 옆이라 띠링이 말소리의 약 8배로 되들어온다 → 띠링 뒤 0.8초 소리를 버린다.
- **띠링 지지직** — 낮은 음 1175Hz 를 스피커가 못 내고(−11dB) 2배음이 더 컸다(10/8 녹음) → 1568 → 2093Hz 로 옮기고 앞뒤 5ms 페이드.
- **닫힘음** — 대화창이 닫힐 때(질문 없이 20초 · 답 끝) 높은 음 → 낮은 음으로 미끄러지며 사라지는 소리(사용자 요청 2026-10-09).

## 준비

- 메인 보드 `68:EE:8F:4F:5D:38`(안경) · USB-C 케이블 · 조용한 방
- **시연·음성비서를 끈다** — 명령 채널은 손님 하나라 도구가 붙으면 음성비서가 끊긴다(도구는 돌고 있으면 스스로 멈춘다).

## 1. 지금 펌웨어 그대로 — 스피커 높이 지도 + 옛 띠링 기준선 (보드 켜기만 · 착용 불필요 · 약 1분)

```bash
cd ~/sop-project/Rpi5/Demo
~/env/tts/.venv/bin/python voice/glass_sound_check.py sweep
~/env/tts/.venv/bin/python voice/glass_sound_check.py chimes --freqs 1175,1568
```

- 🔴 **재는 동안 조용히** — 말소리·손뼉도 소리 덩어리라 띠링으로 센다.
- `chimes --freqs 1175,1568` 은 옛 띠링 기준선이다 — 닫힘음은 「안 들림」이 정상(옛 펌웨어는 `C` 를 모른다).
- **관문 G-a** — sweep 끝줄 「펌웨어 띠링 1568Hz → 깨끗 ✅ · 2093Hz → 깨끗 ✅」 → 2 로.

### 높이 바꾸기 — G-a 미달일 때만

1. sweep 의 「깨끗한 높이」 목록에서 두 개를 고른다(낮은 → 높은 · 예 1760 → 2349).
2. `arduino/glass_voice/glass_voice.ino` 의 `CHIME_LO`·`CHIME_HI` 를 바꾼다 — 닫힘음도 같은 두 높이를 쓴다.
3. `python3 selftest/test_glass_sound_check.py` 통과 → 커밋 → 2 로.

## 2. 굽기 (USB 연결 · 약 5~10분)

```bash
bash ~/sop-project/Rpi5/arduino/flash_esp32.sh main
```

- 시리얼번호로 메인만 고른다 → **8MB 전체 백업 + 대조가 통과해야만** 굽는다 → 끝에 IP 를 `Demo/.camera_ip` 에 적는다(옛 값은 `~/lab/esp32-link/camera_ip.bak-*`).
- **되돌리기** = 스크립트가 출력한 `esptool --port … --no-stub write-flash 0 <백업>` 한 줄.
- 굽고 나면 부팅 띠링이 새 소리(높아짐)로 난다. USB 를 빼고 배터리로 켜도 된다.

## 3. 새 띠링·닫힘음 (약 30초)

```bash
~/env/tts/.venv/bin/python voice/glass_sound_check.py chimes
```

**관문 G-b**(고정) — 도구가 ✅/🔴 를 찍는다 · 👀 는 사용자

| 관문 | 기준 |
|---|---|
| 띠링 들림 | 3번 · 자리 의심 0 |
| 띠링 깨끗 | 두 음 모두 배음 < 10% |
| 닫힘음 | 3번 들림 · 높이가 내려감 · 2배음 < 10% |
| 👀 귀 | 띠링이 선명(딸깍·지지직 없음) · 닫힘음이 「낮아지며 꺼지는」 느낌 |

## 4. 착용 시험 — 증폭 · 메아리 · 닫힘음 (안경 착용 · 배터리 · 약 10분)

**시연 전체를 켠 상태로**(측정 도구 정합 설계 D16 — 기능끼리 부하를 주고받는다):

```bash
D=~/lab/voice-capture/착용시험_$(date +%Y%m%d_%H%M%S); mkdir -p "$D"
cd ~/sop-project/Rpi5/Demo && SOP_VOICE_AUDIO="$D" SOP_VOICE_METRICS="$D/metrics.jsonl" bash run_demo.sh
```

- 화면이 없는 자리면 음성비서만: `SOP_VOICE_AUDIO="$D" SOP_VOICE_METRICS="$D/metrics.jsonl" ./run_voice.sh` — ⚠️ 통합 조건이 아니라고 결과에 적는다.
- 「작업 시작」은 안 눌러도 된다(작업 전이면 「작업 시작 전」으로 답한다 — 이 시험은 호출·메아리·닫힘음을 본다).

**대본** — 한 줄에 한 번씩. **못 알아들으면(띠링이 안 나면) 다시 부르지 말고 다음 줄로** 간다(그래야 호출 수가 정직하다).

| # | 할 것 |
|---|---|
| 1~10 | 「가디언」 → 띠링 → 질문 → 답·닫힘음 듣기 · 질문 = ①지금 몇 단계야? ②지금 무슨 단계야? ③지금 눌러야 하는 버튼이 뭐야? ④다음에 뭐 눌러야 돼? ⑤다음 순서 뭐야? ⑥이번 단계에 무슨 공구 필요해? ⑦앞에 보이는 게 뭐야? ⑧지금 보이는 공구가 뭐야? ⑨작업 결과 어때? ⑩지금 상태 어때? |
| 11~12 | 「가디언」 → 띠링 → **아무 말 없이 20초** → 닫힘음 듣기 |
| 13 | 조용히 30초 |
| 14 | 손으로 안경 프레임을 10초 만진다 |

끝나면 시연을 닫고 채점:

```bash
python3 voice/glass_sound_check.py score "$D" "$(ls -t logs/voice_*.log | head -1)"
```

**관문 G-c**(고정) — 👀 는 타임라인을 보고 사용자와 함께

| 관문 | 기준 |
|---|---|
| 호출 인식 | ≥ 10/12 |
| 띠링 메아리 발화 | 0 |
| 헛호출 | 0(13·14 구간) 👀 |
| 엉뚱한 질문 | 0 👀 |
| 답 뒤 헛발화 | 0(다음 호출은 정상) 👀 |
| 닫힘음 | 질문 없는 호출 2번 → 「질문 없음」 2 · 귀로도 들림 👀 |

## 중단 규칙

- 백업 대조 실패 → **굽지 않는다.**
- G-b 미달 → 착용 시험을 하지 않고 보고한다(띠링이 바뀌지 않았으면 메아리 조건이 다르다).
- G-c 미달 → **그 자리에서 값(증폭 배율 · 버림 시간)을 바꾸지 않는다** — 조정용 세션을 따로 둔다(같은 기록으로 값을 고르면 선택 편향 · 저널 §12.74). 되돌리기 = `SOP_MIC_GAIN=1` · `voice_assistant.CHIME_MUTE_SEC = 0`.
