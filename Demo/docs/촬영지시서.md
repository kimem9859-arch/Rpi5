# 라벨링 사진 촬영 지시서 — 장소2·장소3

장소2(학습·검증)와 장소3(시험 전용)에서 라벨링할 사진을 찍는 순서입니다. 도구는 `Demo/test/capture_dataset.py` 하나입니다. 이 도구는 시연 프로그램과 같은 그림(1024×768 · 반전 → 왜곡보정 → 회전 · 무손실 PNG)을 저장합니다.

> 근거 — 장면 = 데이터확보 설계서(`docs/superpowers/specs/2026-09-16-비전모델-데이터확보-design.md`) §5 · 시간표·목표 = 2026-10-01 사용자 승인(장소1 실측으로 계산) · 장소3 라벨 흐름 = 반자동 라벨링 설계 §7-b.

## 1. 가져갈 것

콘솔 · 파이 · 모니터 · 공유기(iptime) · 카메라 안경(ESP32) · 공구 3종(driver·wrench·pliers) · 장갑.

🔴 **펌웨어를 다시 굽지 않습니다.** 장소1 사진은 XGA · 노출 9ms 펌웨어로 찍었습니다. 세 장소가 같은 조건이어야 합니다.

## 2. 시작 순서

1. **공유기를 먼저 켜고 1분 기다린 뒤** 카메라 안경을 켭니다. 안경이 먼저 켜지면 폰 핫스팟에 붙어 그날 내내 느려질 수 있습니다(화면은 멀쩡해 보입니다).
2. **카메라 주소를 확인합니다(10초).** 안경 보드는 시리얼번호 `3C:0F:02:DD:5E:58` 입니다 — `ttyACM` 번호는 꽂는 순서로 바뀌므로 번호로 고르지 않습니다.

   ```bash
   python3 -c "from serial.tools import list_ports; [print(p.device, p.serial_number) for p in list_ports.comports() if p.vid]"
   bash ~/sop-project/Rpi5/arduino/read_esp32_ip.sh /dev/ttyACM0    # ← 위에서 5E:58 인 포트
   ```

   `192.168.1.x` 면 정상입니다. `10.47.16.x` 면 **안경만** 껐다 켭니다.
3. **촬영 도구를 켭니다.** 장소는 켤 때 정하고, 촬영 중에는 바꿀 수 없습니다.

   ```bash
   cd ~/sop-project/Rpi5/Demo
   DISPLAY=:0 python3 test/capture_dataset.py --place 장소2     # 장소3 이면 --place 장소3
   ```

   장소3 사진은 `~/data/capture_장소3/` 에 따로 저장됩니다(장소2 = `~/data/capture/`).

## 3. 화면과 키

창 위쪽 띠에 `장소2 · 7 쥔공구 · ● 녹화 01:23 · 345장` 처럼 지금 장소·장면·녹화 시간·장수가 나옵니다. 창을 한 번 클릭해야 키가 먹습니다.

| 키 | 하는 일 |
|---|---|
| <kbd>s</kbd> | 다음 장면(대기 중에만 바뀝니다) |
| <kbd>space</kbd> | 녹화 시작 / 정지 — 정지할 때마다 장면 폴더 하나가 생깁니다 |
| <kbd>q</kbd> | 끝내기 |

녹화하다 끊겨도 괜찮습니다. 같은 장면을 다시 <kbd>space</kbd> 로 이어 찍으면 폴더가 하나 더 생길 뿐입니다.

## 4. 촬영 시간표

**공통 규칙**
- 장면마다 **앞 절반은 맨손, 뒤 절반은 장갑**으로 찍습니다.
- 「바꿔 가며」 목록을 **정한 시간 동안 처음부터 끝까지 반복**합니다(몇 번 하라는 지시가 아닙니다).
- 얼굴·개인정보가 화면에 들어오지 않게 합니다.
- 빛 반사 장면(설계서 5번)은 조명이 없어 뺐습니다.

| 장면 | 바꿔 가며 | 장소2 | 장소3 |
|---|---|---|---|
| 0 정지 | 콘솔 정면을 가만히 — 묶음 도구의 기준 사진 | 20초 | 20초 |
| 1 콘솔전체 | 거리 3단계 × 각도(정면·좌·우·위·아래) | 3분 | 1분 |

| 4 머리움직임 | 콘솔을 보며 좌우·위아래 | 2분 | 1분 |

## 5. 끝나고 — 현장에서 장수 세기(장비를 걷기 전에)

```bash
cd ~/sop-project/Rpi5/Demo
python3 test/capture_dataset.py --place 장소2 --count     # 장소3 이면 --place 장소3
```

묶음 도구와 같은 기준(깨짐·검은 화면·장소 전체 중복)으로 걸러 장면별로 남는 장수를 보여 줍니다. 8,000장이면 5분 안팎 걸립니다.

- 모두 ✅ 면 끝입니다.
- ❌ 가 나오면 **그 장면을 모자란 장수 ÷ 160 분만큼 더 찍고** 다시 셉니다(1분에 쓸 수 있는 사진 약 160장).

**최소 기준**(정본 = `capture_dataset.py` 의 `MIN_KEEP` — 장수 세기가 판정합니다)

| 장소 | 장면 | 남아야 할 장수 | 목표 |
|---|---|---|---|
| 장소2 | 6+7(공구) | 2,000 | 장소1 과 합쳐 클래스당 1,500장(설계서 §6) — 가장 적은 driver 기준 |
| 장소3 | 6+7(공구) | 1,000 | 시험 세트 클래스당 300장 |
| 장소3 | 7(쥔 공구) | 320 | 손톱이 버튼으로 잡히는 오검출을 셀 쥔 공구 300장 |
| 장소3 | 8(배경) | 110 | 물체 없는 사진 100장 |

버튼은 따로 세지 않습니다 — 장소1 실측으로 클래스당 목표의 3배를 넘습니다.
